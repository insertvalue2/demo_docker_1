컨테이너에서 실행 중

도커 파일 실행 프로젝트

이 화면이 보이면 Spring Boot 앱이 Docker 컨테이너 안에서 정상적으로 실행되고 있는 것입니다.

코드가 화면이 되기까지

1

jar 만들기

Gradle이 내 코드를 실행 가능한 jar 파일로 묶습니다.

./gradlew clean build -x test
2

이미지 만들기

Dockerfile대로 Java 21 위에 jar를 담아 이미지를 만듭니다.

docker build -t spring-blog .
3

컨테이너 실행

이미지로 컨테이너를 띄우고, 키는 .env에서 넘깁니다.

docker run -d -p 8080:8080 --env-file .env --name blog spring-blog

Dockerfile

FROM amazoncorretto:21                   # 프로젝트와 같은 Java 21
COPY build/libs/*SNAPSHOT.jar /app.jar   # 실행용 jar만 복사
ENTRYPOINT ["java", "-jar", "/app.jar"]  # 컨테이너가 켜질 때마다 서버 실행

이 페이지는 어디에 있나요?

src/main/resources/static/index.html 입니다. 이 폴더의 파일은 jar 안에 함께 담겨, 컨테이너에서도 localhost:8080 첫 화면으로 보입니다.

코드를 고쳤다면

  • ./gradlew clean build -x test
  • docker build -t spring-blog .
  • docker rm -f blog
  • docker run (위 3번 명령)

키는 이미지에 넣지 않습니다

SMS 키 같은 비밀 값은 .env에 두고 실행할 때 --env-file .env로 넘깁니다. .env는 .dockerignore와 .gitignore에 적어 둡니다.

상태 확인 명령

  • docker ps : 실행 중인 컨테이너
  • docker logs -f --tail 5 blog : 실시간 로그
  • docker rm -f blog : 컨테이너 정리
